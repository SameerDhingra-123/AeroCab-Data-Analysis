# 🚖 AeroCab Data Analysis Project

## 📌 Project Description

The AeroCab Data Analysis project focuses on exploring and visualizing cab booking data to uncover meaningful business insights. The objective of this project is to analyze ride patterns, customer behavior, and revenue trends to support data-driven decision-making.

Using Power BI, the dataset was cleaned, transformed, and modeled to create an interactive dashboard that highlights key performance indicators such as total bookings, revenue generation, peak usage hours, and customer trends.

This project demonstrates the ability to work with real-world data, perform data cleaning, and present insights in a clear and visually appealing manner.

---

## 🎯 Objectives

* Analyze cab booking trends and ride frequency
* Identify peak hours and high-demand periods
* Understand revenue distribution and growth patterns
* Provide actionable insights for business improvement

---

## 🛠 Tools & Technologies

* Power BI (Data Visualization & Dashboarding)
* Data Cleaning & Transformation
* Basic Data Analysis Techniques

---

## 📊 Key Insights

* Identified peak booking hours with highest demand
* Analyzed revenue contribution across different time periods
* Observed customer usage patterns and trends
